# コピー先フォルダ作成確認 設計

## 意図

存在しないコピー先フォルダをユーザーが把握し、コピー操作の承認時にだけ新規作成できるようにする。

## 目標

- 選択された各ドライブのコピー先相対パスについて、未存在のフォルダを検出する。
- コピー確認ダイアログに新規作成対象を表示する。
- ユーザーがコピーを承認した場合だけ、コピー処理が必要なフォルダを作成する。

## 対象外

- コピー先ドライブそのものの作成や接続。
- 既存の同名ファイル・フォルダ競合ルールの変更。
- 保存済みパターンの形式変更。

## 方針

コピー先の解決時に、存在しないフォルダだけを収集する。確認文にはコピー元・コピー先に加えて `新規作成するフォルダ` の一覧を表示する。ユーザーが `はい` を選択した場合に限り、その一覧を `New-Item -ItemType Directory -Force` で作成してから既存のコピー処理を開始する。

別案として、コピー処理中に初めて親フォルダを作る方法があるが、作成対象を確認できず今回の要件に合わないため採用しない。

## 制約と検証

- Windows PowerShell 5.1 互換性を維持し、変更する PowerShell ファイルは UTF-8 BOM のまま保存する。
- コアのフォルダ検出ヘルパーを実データでPesterテストし、未存在だけが対象になることを確認する。
- Windows PowerShell 5.1 上で全Pesterテストを実行する。
