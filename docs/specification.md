# Multi Drive Copy 仕様書

## 目的・対象環境

エクスプローラーで選択した複数ファイル・フォルダを、E・F・Gドライブの同じ相対パスへコピーする。Windows 10/11 と標準搭載 Windows PowerShell 5.1 を対象とする。管理者権限・外部依存は不要。

## 起動方法

`Install.ps1` が実装スクリプトを `%LOCALAPPDATA%\Programs\MultiDriveCopy` に配置し、「送る」メニューへショートカットを登録する。複数選択時のフルパスを起動引数として受け取る。

- 通常起動（`E F G に一括コピー`）は設定画面を表示する。
- 保存済みパターンの直接実行（`E F G に一括コピー - <パターン名>`）は、設定画面を表示せずにコピーを開始する。
- ごみ箱移動を有効にしたパターンの直接実行（`E F G に一括コピー（検証してごみ箱へ） - <パターン名>`）は、設定画面を表示せずにコピーし、続けて検証結果ダイアログを表示する。移動はそのダイアログでの最終確認後にだけ実行する。
- パターンの保存・削除時とインストール時に、直接実行用ショートカットを保存内容に合わせて更新する。
- 外部連携（`-SourceListFile`）では設定画面を表示し、読み込んだ一覧を確認してからコピーする。無確認の自動コピーは行わない。
- 選択がない場合はコピー開始不可とする。

## UI要件

- コピー元リストを表示し、存在するパスのみ受理する。
- コピー先はドライブ文字なしの共通相対パスで指定する。
- E / F / G のチェックを変更して対象ドライブを指定する。
- 名前付き相対パスと対象ドライブの組を保存・選択・削除でき、JSONに永続化する。
- コピー開始前に選択数とコピー先を確認する。
- 直接実行では設定画面を表示せず、小型の進捗画面とキャンセル操作のみを表示する。進捗画面にはコピー元の件数とコピー先を表示する。
- 直接実行の正常終了は Windows 通知で知らせ、完了ダイアログや設定画面を残さない。
- 直接実行でも、同名競合・エラー・ドライブ未接続・新規フォルダ作成など判断が必要な場合だけダイアログを表示する。
- 設定画面に「コピー後、検証済みの元データをごみ箱へ移動」チェックボックスを置く。既定は OFF とし、危険な設定であることを文言で明示する。このチェック状態はプリセットに保存しない。
- チェックが ON の場合は、コピー後に検証結果ダイアログを表示し、検証成功・不一致・保護・移動結果の内訳をファイル単位／フォルダ単位で表示する。

## コピー仕様

コピー元の各項目名を保持して指定先へ配置する（`C:\Work\a.txt` → `E:\Backup\a.txt`）。未作成ディレクトリは作成し、同名ディレクトリは再帰的に統合する。ドライブ未接続、相対パス不正、コピー元自身またはその子孫へのコピーは処理前に拒否する。ドライブごとに処理する。

直接実行では保存済みパターンの対象ドライブを使用する。保存されたドライブがない旧形式のパターンは E / F / G を対象とする。対象ドライブの一部が未接続の場合は、接続済みドライブのみで続行するか確認する。すべて未接続の場合は理由を表示して中止する。

## 同名ファイルの競合

存在する同名ファイルについて、ユーザーは「上書き」「スキップ」「別名保存」「中止」から選択する。別名保存は `name (1).ext`, `name (2).ext` のように空き名を採用する。「以降にも適用」を選択した場合、以降の同名ファイルに同じ選択を適用する。ファイルとディレクトリで種類が異なる場合、上書きはエラーとする。同名ディレクトリは確認せず統合する。

## 検証とごみ箱移動

対応Issue: #8, #9。設定画面のチェックボックスが ON の場合だけ、コピー完了後に次を行う。既定は OFF とする。チェック状態はパターン保存時にそのパターンの設定として記録し、保存済みパターンの直接実行でも同じ動作を再現する。

1. 実際に転送したコピー元ファイル／フォルダとコピー先の対応を記録する。別名保存は実際の別名パス、スキップは既存のコピー先パス、ディレクトリは実際の作成・統合・別名パスを対応付ける。
2. コピー元が単体ファイルの場合、選択したすべてのコピー先でファイルサイズと SHA-256 を比較する。
3. コピー元がフォルダの場合、配下の全ファイルについて全コピー先でサイズと SHA-256 を比較し、配下の全ディレクトリ（空フォルダを含む）が全コピー先に存在することを確認する。コピー元のファイル数・ディレクトリ構成と、実際にコピーした対応付けが一致することも確認する。
4. コピー元として選択した単体ファイルは、全コピー先で一致した場合にファイル単位の移動候補にする。コピー元として選択したフォルダは、配下の全ファイルと全ディレクトリがすべて一致した場合だけ、フォルダ全体を1つの移動候補にする。スキップは既存内容が一致した場合だけ候補に含める。
5. 不一致、コピー先不足、コピー元消失、コピー後の追加・削除・変更、読み取りエラー、中止、未接続ドライブがある場合は移動しない。フォルダの一部だけを移動する部分移動は行わない。
6. コピー元が入れ子・重複している場合、またはフォルダ内にジャンクション／シンボリックリンク等の再解析ポイントがある場合は、安全のため移動候補にしない。
7. 移動候補がある場合、ファイル／フォルダの種別、件数、合計サイズ、元パスを表示して最終確認する。最終確認後、移動直前にもう一度コピー元・コピー先・フォルダ構造を照合する。変更を検出した場合は移動しない。
8. 元データは Windows のごみ箱へ移動し、完全削除へフォールバックしない。フォルダは配下ごと移動し、元の名前・場所へ復元できるようにする。
9. 検証・移動の結果を `%APPDATA%\MultiDriveCopy\logs\verify-<日時>.log` に記録する。ログにはファイル単位／フォルダ単位、コピー元、実際のコピー先、ハッシュ、状態、移動成否、リトライ手順を含める。
10. コピー中に中止した場合、コピー処理でエラーが発生した場合、または検証を完了できなかった場合はごみ箱移動を行わない。

## 保存情報

`%APPDATA%\MultiDriveCopy\presets.json` に名前・相対パス・対象ドライブ・ごみ箱移動の有無の組を記録する。ドライブ情報とごみ箱移動の有無は省略可能で、旧形式のファイルもそのまま読み込める。削除操作は確認ダイアログを表示する。アンインストール時に保存情報は残す。

ごみ箱移動を有効にしたパターンは、「送る」に `E F G に一括コピー（検証してごみ箱へ） - <パターン名>.lnk` として登録する。無効なパターンは従来どおり `E F G に一括コピー - <パターン名>.lnk` とする。パターンの保存・削除のたびに両方の接頭辞のショートカットを再作成し、設定と一致しない項目を残さない。

直接実行用ショートカットは「送る」フォルダに `E F G に一括コピー - <パターン名>.lnk` として作成する。ごみ箱移動を有効にしたパターンは `E F G に一括コピー（検証してごみ箱へ） - <パターン名>.lnk` とする。パターン名にファイル名として使えない文字が含まれる場合は `_` に置き換える。引用符や改行を含むパターン名は直接実行ショートカットを作成しない。保存・削除のたびに既存の直接実行ショートカットを再作成し、削除済みパターンの項目や設定と食い違う項目を残さない。

## 外部アプリ連携

外部アプリから大量のコピー元を受け取るため、UTF-8 JSON マニフェストを `-SourceListFile <path>` で読み込む。対応Issue: #7。

### CLI

- `powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File MultiDriveCopy.ps1 -SourceListFile "<manifest>"`
- `-Preset` とは併用できない。併用時は理由を表示して終了コード 1 で終了する。
- 通常の「送る」やコマンドライン引数と併用できる。両方を統合し、重複を除外する。
- マニフェスト読込・検証に失敗した場合も理由を表示して終了コード 1 で終了する。

### マニフェスト形式

```json
{
  "sources": [
    "C:\\full\\path\\a.zip",
    "C:\\full\\path\\folder"
  ]
}
```

- UTF-8（BOM の有無を問わない）。ルートはオブジェクトで、`sources` は文字列の配列とする。
- 各要素は存在するフルパス（ファイルまたはフォルダ）とする。
- 相対パス、空文字、文字列以外、`sources` 以外の型、存在しないパスはエラーとする。
- 重複（大文字小文字・末尾 `\` の違いを含む）は除外する。空の `sources` はエラーとする。
- パス中の空白・日本語はそのまま扱う。引用符などWindowsのファイル名として不正な文字を含むパスは存在確認でエラーとなる。

### 動作

- 受け取った一覧は設定GUIのコピー元リストに表示する。ユーザーが内容を確認してコピーを開始するまで、コピーは実行しない。無確認の自動コピーは行わない。
- 連携起動でもコピー先の選択、プリセット、競合確認、検証後のごみ箱移動は通常起動と同じ動作とする。
- マニフェストは呼び出し元アプリが管理する。ユーザーが書き込める一時領域に適切な権限で作成し、不要になったら削除する。MultiDriveCopy は読み取りのみ行い、マニフェストの作成・移動・削除は行わない。
- MultiDriveCopy 自身は一時ファイルを作成しない。

## 安全性と制約

- 上書きは不可逆。コピー開始時の確認と競合ダイアログで誤操作を減らす。
- コピー済みファイルのロールバックはしない。
- コピー中の失敗はエラーを表示する。
- ごみ箱移動の既定は OFF。ON でも全コピー先で検証済みのファイル／フォルダだけを候補とし、スキップ・別名保存・上書き・ディレクトリ統合の実パスを検証する。
- 中止・エラー・不一致・未接続ドライブ・検証後の変更ではコピー元を移動しない。
- フォルダ移動は、配下の全ファイル・空フォルダを含む構造が全コピー先で一致した場合だけ行う。1ファイルでも不足・相違・追加・読み取り失敗があれば、フォルダの一部だけを移動しない。
- コピー元が入れ子・重複している場合、またはフォルダ内にジャンクション／シンボリックリンク等の再解析ポイントがある場合は移動しない。
- ごみ箱が利用できない場合は移動失敗としてコピー元を残す。完全削除は行わない。フォルダは配下ごとごみ箱へ移動し、元の場所へ復元できる。
- ジャンクション、シンボリックリンク、長大パス、権限制約、低容量媒体等は運用前検証が必要。
- フォルダ統合時、ファイル単位で競合解決する。
- 実機未検証のため、重要なファイルには最初から使用しない。

## 受け入れテスト観点

1. 複数ファイル・フォルダの選択が反映されること
2. E/F/Gの選択と共通相対パスが機能すること
3. 未存在ディレクトリが作成されること
4. 同名競合の4選択と一括適用が動作すること
5. 保存・読込・削除後のパターンが一致すること
6. 存在しないドライブ・自己コピー・配下コピーを防ぐこと
7. キャンセル後に残りのコピーが停止すること
8. インストール／アンインストールで「送る」が更新されること
9. 保存済みパターンの直接実行で設定画面を開かずにコピーできること
10. 直接実行の正常終了で通知が表示され、余分なウィンドウが残らないこと
11. 直接実行の競合・未接続ドライブ・エラーで判断用の表示が出ること
12. 旧形式のプリセット（ドライブ情報なし）がそのまま利用できること
13. ごみ箱移動が既定で OFF であり、パターン保存時にそのパターンの設定として記録されること
13a. ごみ箱移動を有効にしたパターンが「送る」の専用項目として登録され、無効に戻すと通常項目へ戻ること
13b. ごみ箱移動を有効にしたパターンの直接実行で、コピー後に検証結果ダイアログが表示されること
14. 全コピー先で SHA-256 が一致したファイル／フォルダだけが移動候補になること
15. スキップは内容一致時のみ候補、別名保存・ディレクトリ統合は実パスで検証、不一致・中止・エラーは保護されること
16. 移動前の最終確認と移動直前の再検証が行われ、変更を検出したファイル／フォルダは残ること
17. ごみ箱移動後に元の場所へ復元でき、失敗時は完全削除しないこと
18. 検証・移動のログがファイル単位／フォルダ単位で記録されること
19. UTF-8 JSON マニフェストから大量のコピー元を欠落なく読み込めること
20. 空白・日本語を含むパスを扱え、引用符など不正な文字を含むパスはエラーになること
21. 重複・相対パス・存在しないパス・型不正・空配列・不正 JSON をエラーにすること
22. 連携起動でGUIに一覧が表示され、無確認の自動コピーをしないこと
23. 既存の「送る」と保存済みプリセットが維持されること
24. フォルダの全ファイル・空フォルダが全コピー先で一致した場合だけ元フォルダを移動すること
25. 1ファイルでも不足・相違・追加・読み取り失敗があれば元フォルダを一切移動しないこと
26. 入れ子・重複選択、ジャンクション／シンボリックリンクを含むフォルダは移動しないこと
27. フォルダをごみ箱へ移動後、配下と空フォルダを含めて元の場所へ復元できること
