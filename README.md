# Multi Drive Copy

Windows 10/11 向け、複数ドライブへの一括コピーツール。PowerShell 5.1 / Windows Forms を使用し、外部ランタイムや管理者権限は不要です。

## インストール

リポジトリをダウンロードして PowerShell で実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

エクスプローラーでファイル・フォルダを複数選択し、右クリック → **送る** から次の項目を選びます。Windows 11 では「その他のオプションを確認」→「送る」です。

- **E F G に一括コピー**: 設定画面を開いて、コピー先やパターンを編集してからコピーします。
- **E F G に一括コピー - \<パターン名\>**: 保存済みパターンへ設定画面を開かずに直接コピーします。

## 使い方

- 共通の相対パス（例: `Archive\2026`）を入力すると、選択したドライブに同じフォルダ階層でコピーします。
- コピー先ドライブをチェックボックスで選択できます。保存したパターンにはドライブの選択も記録されます。
- 名前付きのコピー先パターンを保存・選択・削除できます（`%APPDATA%\MultiDriveCopy\presets.json`）。保存・削除すると「送る」の直接実行項目も更新されます。
- 最後に選んだパターンは次回起動時にも選択されます。`Ctrl+Enter` でコピー開始、`Alt+S` で保存、`Alt+D` で削除できます。
- 同名ファイルがあれば、上書き / スキップ / 別名で保存 / 中止 を確認します。「以降の競合にも適用」も選べます。直接実行でも同じ確認を表示します。
- フォルダが既に存在する場合は中身を統合します。直接実行で新規フォルダが必要な場合だけ確認します。
- コピー前に対象ファイル数と容量を集計し、進捗バーに全コピー先の転送量を表示します。スキップしたファイルも処理済みとして進み、件数はコピーとスキップを分けて表示します。
- 設定画面から開始する場合は、コピー開始前に最終確認があります。
- 直接実行では小型の進捗画面とキャンセルボタンを表示し、正常終了時は Windows 通知で知らせます。完了ダイアログや設定画面は残りません。
- 直接実行でパターンが見つからない場合、対象ドライブが未接続の場合、コピーに失敗した場合は理由を表示します。
- 設定画面の **コピー後、検証済みの元データをごみ箱へ移動** を有効にすると、コピー後に SHA-256 で全コピー先を検証し、結果の内訳と詳細を表示します。既定は OFF で、この設定はプリセットに保存されません。
- コピー元が単体ファイルの場合は、全コピー先でサイズと SHA-256 が一致したファイルだけが移動候補になります。スキップは内容一致時のみ候補、別名保存は実際の別名パスで検証します。
- コピー元がフォルダの場合は、配下の全ファイルと空フォルダを含むディレクトリ構造が、実際にコピーした全コピー先で一致したときだけ、元フォルダ全体を移動候補にします。1ファイルでも不足・相違・追加・読み取り失敗があれば、フォルダは一切移動しません。
- コピー元が入れ子・重複している場合や、ジャンクション／シンボリックリンクを含むフォルダは、安全のため移動候補にしません。
- 移動前に件数・サイズ・パスを確認し、実行時にもう一度コピー元とコピー先を照合します。検証後の変更やファイル追加を検出した場合は移動しません。
- 元データは Windows のごみ箱へ移動するため、元の場所へ復元できます。完全削除へのフォールバックは行いません。
- 検証と移動の結果は `%APPDATA%\MultiDriveCopy\logs\verify-*.log` にファイル単位／フォルダ単位・対象パス・移動結果を記録します。

## 外部アプリ連携

外部アプリから大量のコピー元を渡す場合は、UTF-8 の JSON マニフェストを `-SourceListFile` で指定します。コマンドライン長の制限を避けられます。

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File "C:\path\MultiDriveCopy.ps1" -SourceListFile "C:\path\sources.json"
```

インストール済みの場合は `%LOCALAPPDATA%\Programs\MultiDriveCopy\MultiDriveCopy.ps1` を指定します。

```json
{
  "sources": [
    "C:\\Work\\Archive\\a.zip",
    "C:\\Work\\Archive\\folder"
  ]
}
```

- `sources` は UTF-8 JSON の文字列配列で、各要素は存在するフルパス（ファイルまたはフォルダ）です。BOM の有無は問いません。
- 起動すると設定画面が開き、読み込んだ一覧を確認してからコピーできます。自動コピーは行いません。
- 同じパスの重複、末尾の `\` の違い、大文字小文字の違いは除外します。通常の引数と併用した場合も重複を除外します。
- 相対パス、存在しないパス、文字列以外、`sources` 配列以外、空の一覧、不正な JSON はエラーです。理由を表示して終了コード 1 で終了します。
- `-Preset`（プリセット直接実行）と `-SourceListFile` は同時に指定できません。
- マニフェストは呼び出し元アプリが管理します。ユーザーが書き込める一時フォルダに適切な権限で作成し、不要になったら削除してください。MultiDriveCopy は読み取るだけで、作成・移動・削除は行いません。
- 既存の「送る」、プリセット、競合処理、検証後のごみ箱移動はそのまま利用できます。

## アンインストール

`Uninstall.ps1` を実行します。保存済みパターンは削除されません。

## 制約

- Windows 専用です。PowerShell 5.1 と .NET Windows Forms が必要です。
- 通常の右クリック直下ではなく「送る」メニューに登録します。
- コピー処理はトランザクションではなく、エラー・キャンセル後もコピー済みファイルは残ります。
- ごみ箱移動を有効にしても、全コピー先で検証が完了したファイル／フォルダだけが対象です。キャンセル・エラー・不一致・入れ子選択・特殊ファイルを含む場合は移動しません。
- シンボリックリンク／ジャンクション等の特殊ファイルは対象外です。
- コピー先がコピー元自身やその配下の場合はコピーできません。
- 実機検証前の初期バージョンです。重要なデータを扱う前にテストしてください。
