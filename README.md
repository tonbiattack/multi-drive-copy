# multi-drive-copy

> **ご利用前に:** このアプリはファイルをコピーし、任意でコピー元をごみ箱へ移動する操作を含みます。**重要なデータは事前にバックアップしてください。** 移動は Windows のごみ箱への移動だけで完全削除は行いませんが、移動した容量はごみ箱を空にするまでディスクの空き容量として戻りません。詳細は [SECURITY.md](SECURITY.md) を参照してください。

**バックアップは、1回の右クリックで3台のドライブへ。**

`multi-drive-copy` は、エクスプローラーで選んだファイル・フォルダを **E / F / G の同じ相対パスへ一括コピー**する Windows 向けツールです。PowerShell 5.1 と Windows Forms だけで動き、外部ランタイムも管理者権限も要りません。コピー後に SHA-256 で全コピー先を検証し、**全ドライブで内容が一致したコピー元だけ**をごみ箱へ移動できます。

## なぜ必要か

同じデータを複数のドライブに置いておきたい場面は多いのに、エクスプローラーで同じ操作を3回繰り返すのは面倒です。かといって、コピーできたつもりで元データを消すのは危険です。転送が途中で止まっている、片方のドライブだけ書き込みに失敗した、といった違いはエクスプローラーの表示からは分かりません。

このアプリは**コピーと検証を1つの操作にまとめ**、元データの移動は「全コピー先で内容が一致した」と確認できた場合だけに限定します。

- **1回の右クリックで複数ドライブへ** — 選択した項目を E / F / G の同一相対パスへ配置
- **検証してから移動** — 全コピー先でサイズと SHA-256 が一致したコピー元だけが移動候補
- **完全削除しない** — Windows のごみ箱へ移すだけ。移動できなければ中止して理由を表示する
- **既定は OFF** — ごみ箱移動は明示的に有効化したときだけ動く

## インストール

リポジトリをダウンロードするか clone して、PowerShell で実行します。

```powershell
git clone https://github.com/tonbiattack/multi-drive-copy.git
cd multi-drive-copy
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

`Install.ps1` は実装スクリプトを `%LOCALAPPDATA%\Programs\MultiDriveCopy` へ配置し、「送る」メニューにショートカットを登録します。管理者権限は不要です。

エクスプローラーでファイル・フォルダを複数選択し、右クリック → **送る** から項目を選びます。Windows 11 では「その他のオプションを確認」→「送る」です。

## 使い方

1. エクスプローラーでコピーしたいファイル・フォルダを複数選択します。
2. 右クリック → 送る → **E F G に一括コピー** を選ぶと設定画面が開きます。
3. コピー先の共通相対パス（例: `Archive\2026`）を入力し、対象ドライブをチェックします。
4. **コピー開始** を押すと、最終確認のあとコピーが始まります。

保存済みパターンを選んだ場合は、設定画面を開かずに小型の進捗画面だけでコピーします。正常終了は Windows 通知で知らせ、完了ダイアログや設定画面は残りません。

### 主な機能

| カテゴリ | 機能 |
| --- | --- |
| コピー | 選択した複数ファイル・フォルダを E / F / G の同一相対パスへ一括コピー |
| コピー | 既存フォルダは再帰的に統合。未作成ディレクトリは確認のうえ作成 |
| コピー | 同名ファイルは「上書き / スキップ / 別名保存 / 中止」から選択。「以降の競合にも適用」に対応 |
| コピー | コピー前にファイル数と容量を集計し、全コピー先の合計に対する進捗を表示 |
| パターン | 名前付きのコピー先相対パスと対象ドライブを保存・選択・削除（`%APPDATA%\MultiDriveCopy\presets.json`） |
| パターン | 保存・削除のたびに「送る」の直接実行項目を自動更新 |
| パターン | パターンごとに「コピー後に検証してごみ箱へ移動」を記録し、右クリック1回で実行 |
| 検証 | 全コピー先でサイズと SHA-256 を比較。スキップ・別名保存・統合は実際のパスで検証 |
| 検証 | フォルダは配下の全ファイルと空フォルダを含む構造が全コピー先で一致した場合だけ候補 |
| 移動 | 検証済みのコピー元だけを Windows のごみ箱へ移動。完全削除へフォールバックしない |
| 移動 | 移動直前にもう一度照合し、検証後の変更・追加を検出したら移動しない |
| 記録 | 検証と移動の結果を `%APPDATA%\MultiDriveCopy\logs\verify-*.log` にファイル単位／フォルダ単位で記録 |
| 連携 | `-SourceListFile` で UTF-8 JSON マニフェストから大量のコピー元を読み込む |
| 操作 | `Ctrl+Enter` でコピー開始、`Alt+S` でパターン保存、`Alt+D` でパターン削除 |

## 検証とごみ箱移動

設定画面の **コピー後、検証済みの元データをごみ箱へ移動** を有効にすると、コピー後に全コピー先を検証し、結果の内訳と詳細を表示します。この設定はパターン保存時に記録され、次回以降は「送る」の **E F G に一括コピー（検証してごみ箱へ） - \<パターン名\>** から右クリック1回で同じ動作を実行できます。

| コピー元 | 移動候補になる条件 |
| --- | --- |
| 単体ファイル | 全コピー先でサイズと SHA-256 が一致 |
| フォルダ | 配下の全ファイルと空フォルダを含むディレクトリ構造が、実際にコピーした全コピー先で一致 |

- スキップは既存内容が一致した場合だけ候補にします。別名保存は実際の別名パスで検証します。
- 1ファイルでも不足・相違・追加・読み取り失敗があれば、フォルダは一切移動しません。部分移動は行いません。
- コピー元が入れ子・重複している場合や、ジャンクション／シンボリックリンクを含むフォルダは移動候補にしません。
- 移動前に件数・サイズ・パスを確認し、実行時にもう一度コピー元とコピー先を照合します。検証後の変更やファイル追加を検出した場合は移動しません。
- 元データは Windows のごみ箱へ移動するため、元の場所へ復元できます。完全削除へのフォールバックは行いません。
- 中止・エラー・不一致・未接続ドライブがある場合は移動しません。

検証と移動の結果は `%APPDATA%\MultiDriveCopy\logs\verify-*.log` に、ファイル単位／フォルダ単位・対象パス・移動結果として記録します。

> **移動前に必ずバックアップしてください。** ごみ箱への移動はバックアップの代わりにはなりません。本アプリは全コピー先の一致を検証しますが、重要なデータの唯一のコピーを移動する用途には使わないでください。

## 外部アプリ連携

外部アプリから大量のコピー元を渡す場合は、UTF-8 の JSON マニフェストを `-SourceListFile` で指定します。コマンドライン長の制限を避けられます。

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File "C:\path\MultiDriveCopy.ps1" -SourceListFile "C:\path\sources.json"
```

インストール済みの場合は `%LOCALAPPDATA%\Programs\MultiDriveCopy\MultiDriveCopy.ps1` を指定します。

```json
{
  "sources": [
    "C:\\Work\\Archive\\a.zip",
    "C:\\Work\\Archive\\folder"
  ]
}
```

- `sources` は UTF-8 JSON の文字列配列で、各要素は存在するフルパス（ファイルまたはフォルダ）です。BOM の有無は問いません。
- 起動すると設定画面が開き、読み込んだ一覧を確認してからコピーできます。自動コピーは行いません。
- 同じパスの重複、末尾の `\` の違い、大文字小文字の違いは除外します。通常の引数と併用した場合も重複を除外します。
- 相対パス、存在しないパス、文字列以外、`sources` 配列以外、空の一覧、不正な JSON はエラーです。理由を表示して終了コード 1 で終了します。
- `-Preset`（パターン直接実行）と `-SourceListFile` は同時に指定できません。
- マニフェストは呼び出し元アプリが管理します。ユーザーが書き込める一時フォルダに適切な権限で作成し、不要になったら削除してください。MultiDriveCopy は読み取るだけで、作成・移動・削除は行いません。
- 既存の「送る」、パターン、競合処理、検証後のごみ箱移動はそのまま利用できます。

## テスト

[Pester](https://github.com/pester/Pester) 3.4（Windows PowerShell 5.1 に同梱）で実行します。

```powershell
powershell.exe -NoProfile -Command "Import-Module Pester -RequiredVersion 3.4.0; Invoke-Pester -Path .\tests"
```

テストは一時ディレクトリ内でのみ破壊的操作を行い、コピー進捗、競合処理、パターン設定の往復、ショートカット生成、ソースリストの読み込み、ファイル／フォルダ検証、ジャンクション検出、検証後の変更検出などを確認します。CI（[`.github/workflows/ci.yml`](.github/workflows/ci.yml)）は Windows 上で全テストと PowerShell 5.1 の構文チェックを実行します。

## 制約

- Windows 専用です。PowerShell 5.1 と .NET Windows Forms が必要です。
- 通常の右クリック直下ではなく「送る」メニューに登録します。
- コピー処理はトランザクションではなく、エラー・キャンセル後もコピー済みファイルは残ります。
- ごみ箱移動を有効にしても、全コピー先で検証が完了したファイル／フォルダだけが対象です。キャンセル・エラー・不一致・入れ子選択・特殊ファイルを含む場合は移動しません。
- シンボリックリンク／ジャンクション等の特殊ファイルは対象外です。
- コピー先がコピー元自身やその配下の場合はコピーできません。
- 実機検証前の初期バージョンです。重要なデータを扱う前にテストしてください。

詳細は [仕様書](docs/specification.md) を参照してください。

## セキュリティと注意事項

**重要なデータは事前にバックアップしてください。** このアプリはファイルをコピーし、移動する操作を含みます。

- 削除は Windows のごみ箱への移動だけで、完全削除は行いません。ごみ箱非対応の環境では中止して理由を表示します。
- ごみ箱移動は既定で OFF です。有効化した場合も、全コピー先で検証済みの項目だけが対象です。
- ごみ箱へ移動した容量は、**ごみ箱を空にするまでディスクの空き容量として戻りません**。
- コピーは上書きを含みます。上書きは不可逆です。
- ネットワークへは一切アクセスしません。テレメトリも送信しません。

詳細と既知の制約は [SECURITY.md](SECURITY.md) を参照してください。
